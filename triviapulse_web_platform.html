How to Host This Website for Free ($0)

No App Store fees, no server costs, works on iPhone & Android browsers.

Method 1: GitHub Pages (100% Free Forever) Recommended
  1. Create a free account at github.com.
  2. Create a new repository named trivia-pulse (set to Public).
  3. Upload this exact file and name it index.html.
  4. Go to Settings → Pages, set branch to main and folder to / (root), and save.
  5. Your site is live instantly at https://yourusername.github.io/trivia-pulse!
Method 2: Vercel (Instant Drag-and-Drop)

Head to vercel.com, log in, drag-and-drop a folder containing this index.html file, and get an immediate custom URL (e.g., triviapulse.vercel.app) with free SSL and worldwide CDN speed.

📱 Mobile Full-Screen App Icon: When opened on an iPhone Safari, tap Share → "Add to Home Screen". It launches without address bars just like a native App Store game.
