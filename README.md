# TriviaPulse 🧠⚡

A competitive, mobile-first Progressive Web App (PWA) trivia game featuring ranked matchmaking, cloud persistence, and an infinite stream of questions. Built to provide a premium, ad-free trivia experience across all devices without the need for app store downloads.

## ✨ Features

*   **Competitive Ranked Mode:** Climb division tiers and earn XP with a custom real-time scoring and RP (Ranked Points) engine.
*   **Massive Question Library:** Integrated with the OpenTDB API to stream 10,000+ questions across specialized domains including Pop Culture, History, Music, and Movies.
*   **Anti-Repetition Shield:** Smart filtering ensures you never encounter the same question twice.
*   **Post-Match Analysis:** Review your performance with a detailed post-match screen and answer explanations.
*   **Cloud Authentication:** Seamless login and progress syncing via Firebase (supports Google, GitHub, Email/Password, and Guest accounts).
*   **Dynamic Audio Engine:** Custom slot-machine-style background music generated via the Web Audio API, complete with full volume control.

## 🛠️ Tech Stack

*   **Frontend:** HTML5, CSS3, JavaScript (ES6+)
*   **Architecture:** Progressive Web App (PWA), fully responsive mobile-first design
*   **Backend / Auth:** Firebase Authentication and Cloud Data
*   **Data Source:** Open Trivia Database (OpenTDB) API
*   **Audio:** Web Audio API
